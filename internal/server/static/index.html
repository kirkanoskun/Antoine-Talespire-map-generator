Le Cartographe

Cartes TaleSpire à partir d’une description

Décrivez la carte que vous imaginez

Racontez la scène comme à votre table : le décor, l’ambiance, les éléments clés. Le Cartographe prépare un prompt pour votre assistant IA, puis transforme sa réponse en carte TaleSpire.

    Options avancées

    Votre prompt est prêt

    Il reste à le confier à l’assistant IA de votre choix (ChatGPT, Claude, Gemini…) :

    1. Copiez le prompt et collez-le dans une nouvelle conversation.
    2. L’IA vous pose d’abord trois questions (ambiance, point fort de la scène, passages) : répondez-y.
    3. Elle renvoie alors la carte : copiez toute sa réponse, texte compris, et revenez ici.

    Voir le prompt (rédigé en anglais pour l’IA, qui vous répondra en français)

    Collez la réponse de l’IA

    Copiez toute sa réponse, même avec du texte autour : le Cartographe y retrouve la carte, la vérifie et la dessine.
