Décrivez la carte que vous imaginez

Racontez la scène comme à votre table de jeu : le décor, l'ambiance, les éléments clés. Le Cartographe prépare un prompt prêt à confier à votre assistant IA.

Ou partez d'un exemple
Bâtiments importés

Ajoutez un code Slab pour réutiliser sa construction dans vos cartes. Les bâtiments disponibles seront inclus dans le prochain prompt.

    L’emprise est estimée à partir des positions des objets. Agrandissez-la pour les toits ou les éléments qui dépassent.

    Options avancées

    Confiez ce prompt à votre IA

    Copiez le prompt ci-dessous et collez-le dans l'assistant IA de votre choix (ChatGPT, Claude, Gemini…). Il vous renverra un JSON : copiez-le, puis passez à l'étape suivante.

    💡Astuce : demandez à l'IA de ne renvoyer que le JSON. Le prompt le lui précise déjà.

    Chargez le JSON de la carte

    Collez le JSON renvoyé par votre IA (ou le vôtre). Le Cartographe le valide, dessine la carte et prépare le code TaleSpire.
